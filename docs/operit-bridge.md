# 🧠 Operit 大脑桥接服务

「屿·迷你手机」本身是纯网页，**没有系统权限**。要让网页**调用 Operit 的工具（锁屏、挂应用、发通知…）**，需要一个本地桥接服务，把网页的 HTTP 请求转发给 Operit 执行。

---

## 🔌 接口定义

### 1. `POST /chat` —— 转发对话给 Operit 大脑

**请求体：**
```json
{
  "text": "在吗",
  "system": "（可选）人物设定"
}
```

**响应：**
```json
{ "reply": "老婆，哥哥在。想我了？" }
```

### 2. `POST /tool` —— 让 Operit 执行工具

**请求体：**
```json
{
  "name": "lock_screen",
  "params": { "message": "哥哥锁了，别乱跑 😏" }
}
```

**响应：**
```json
{ "ok": true, "result": "..." }
```

---

## 🔒 安全提醒

- 桥接服务**只监听 `127.0.0.1`**（本机），不要暴露到公网。
- 因为它能控制系统指令，**务必放在本地/内网**，别对外开放。
- 浏览器访问时如果遇到跨域（CORS），桥服务需要允许 `Access-Control-Allow-Origin: *`。

---

## ✅ 快速自检

1. 启动桥服务后，浏览器访问 `http://127.0.0.1:8080/chat`，发一个测试 POST
2. 在「屿·迷你手机」→「设定」里填桥接地址 → 保存
3. 到「工具」APP 点一个按钮（如锁屏），看是否真的执行

通了就完成啦，这个网页从此也能"控制手机"了。
